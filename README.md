# clubargen-web

Sitio del Club Social y Deportivo Argentino.

- Páginas: `index.html`, `partidos.html`, `equipos.html`, `club.html`, `socios.html`, `sumate.html`.
- **Datos que se actualizan** (próxima fecha, resultados, planteles, noticias): `js/data.js`. El diseño no se toca para eso.
- Estilos: `css/site.css`. Lógica: `js/site.js`.
- Sitio estático, sin build: se publica tal cual con GitHub Pages.
